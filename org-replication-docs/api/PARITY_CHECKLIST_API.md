# Parity Checklist API

Use in PRs and release checks.

- [ ] All required endpoints from `FEATURE_CONTRACT_API_V1.md` exist.
- [ ] Request/response schemas match contract.
- [ ] Error codes and error payload shape match contract.
- [ ] Auth and role checks match contract.
- [ ] Pagination/sorting/filtering behavior matches contract.
- [ ] Backward compatibility checks completed.
- [ ] Required logs/metrics/traces are implemented.
- [ ] Security controls and rate limits are applied.
- [ ] API tests in `TEST_MATRIX_API.md` pass.
- [ ] Change notes added for consumers.
